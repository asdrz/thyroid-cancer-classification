# Project description
This project implements a comprehensive machine learning and exploratory data analysis applied to a medical dataset on thyroid cancer. The aim is to predict patients’ response to treatment based on clinical and histological variables, whilst managing class imbalances. The dataset used comes from Kaggle and can be found at the following address: https://www.kaggle.com/datasets/jainaru/thyroid-disease-data/data.

# Key steps
- **Data pre-processing**: Cleaning, ordinal/binary/one-hot encoding, duplicate handling and scaling (`StandardScaler`).
- **Exploratory Data Analysis (EDA)**: Statistical visualisations (distributions, correlation matrices) to identify patient profiles.
- **Modelling & Evaluation**: Training classifiers (Random Forest, SVM, KNN) with cross-validation and confusion matrices.

# Packages
- **Python** (Pandas, NumPy, Scikit-Learn, Imbalanced-learn)
- **Visualisation**: Matplotlib, Seaborn
